# 客服知识库：报销与差旅 FAQ

## 报销时限

差旅结束后 7 个工作日内在报销系统提交，超期未报销的每逾期一个月扣减报销金额的 1%，最高扣 10%。月度报销截止日为每月 25 日，25 日之后提交的顺延到下月处理。

## 发票要求

电子发票需为增值税电子普通发票或电子专用发票，抬头必须为公司全称"某某科技有限公司"，税号在 OA 首页"常用信息"查询。出租车发票需附行程单，餐费发票需注明参与人员及事由。发票在税务局全国发票查验平台验真后再提交。

## 报销进度查询

在报销系统"我的单据"里查看状态：待主管审批、待财务复核、已付款。付款到账时间：5000 元以下 3 个工作日，以上 5 个工作日。审批卡住超过 2 个工作日可在企业微信催办。

## 差旅预订

机票和酒店通过公司差旅平台"程无忧"统一预订，事前审批通过后才能订票。因私延期产生的差价自理。高铁票可在 12306 自行购买后随行程单报销。
