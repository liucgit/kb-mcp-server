# 客服知识库：网络与权限 FAQ

## VPN 使用

远程办公先安装 EasyConnect 客户端，账号与域账号一致。研发人员需额外申请代码仓库与测试环境网段权限。备用入口 acc.abc-vpn.com。VPN 掉线先检查是否与本机安全软件冲突，再尝试切换备用入口。

## 生产环境访问权限

生产环境访问必须走堡垒机，权限按"最小必要"原则审批：在 OA 提交《生产权限申请》，写明访问的系统、网段、期限与事由，经系统 Owner 与安全部双重审批后开通，到期自动回收。严禁共享堡垒机账号。

## Wi-Fi 连接

办公 Wi-Fi：ABC-Office，账号为域账号；访客 Wi-Fi：ABC-Guest，密码每周一由前台更新。办公与访客网络隔离，访客无法访问任何内部系统。会议室若有独立 IoT Wi-Fi（ABC-IoT）仅供智能设备使用。

## 软件安装权限

办公电脑默认无管理员权限。安装标准软件（IDEA、浏览器等）走"软件商店"自助安装；需要管理员权限的特殊软件，提交工单说明用途，IT 处远程协助安装。禁止自行安装破解软件，EDR 会自动告警。
